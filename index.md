## O čem tenhle web je

Tady si můžete napsat pár vět o sobě, svém projektu nebo firmě. Klidně to
uprav podle sebe — celá stránka je jen obyčejný Markdown soubor
(`index.md`), takže úpravy jsou hračka.

## Co tu najdete

- 📄 Jednoduché stránky psané v Markdownu
- 🎨 Hezký vzhled díky předpřipravenému Jekyll tématu
- 🚀 Automatické nasazení přes GitHub Pages

## Jak to spustit

1. Vytvoř si na GitHubu repozitář (např. `tvoje-jmeno.github.io`, nebo
   jakýkoliv jiný název).
2. Nahraj do něj soubory `_config.yml` a `index.md`.
3. V nastavení repozitáře (**Settings → Pages**) zapni GitHub Pages a
   jako zdroj vyber větev `main` a složku `/ (root)`.
4. Za pár minut bude web dostupný na adrese
   `https://tvoje-jmeno.github.io/nazev-repozitare/`.
